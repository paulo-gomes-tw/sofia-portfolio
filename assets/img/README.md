# Imagens

Dois arquivos são carregados diretamente pelo CSS. Enquanto eles não existem,
o CSS cai automaticamente na camada de gradiente definida logo abaixo da
`url()` — nada quebra, mas a foto real não aparece.

| Arquivo               | Onde aparece            | Formato sugerido            |
| --------------------- | ----------------------- | --------------------------- |
| `hero.png`            | fundo do Hero           | paisagem, ≥ 2400px de largura |
| `about-foto.jpg`      | retrato da seção Sobre  | retrato 4:5, ≥ 1200px de largura |
| `servico-branding.jpg`| bloco “Branding e Identidade Visual” (Serviços) | paisagem 4:3, ≥ 1400px de largura |
| `servico-social-1.jpg` … `servico-social-6.jpg` | grade de posts do bloco “Design para rede social” | retrato 4:5, ≥ 800px de largura |

Basta salvar os arquivos com esses nomes nesta pasta.
