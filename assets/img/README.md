# Imagens

Dois arquivos são carregados diretamente pelo CSS. Enquanto eles não existem,
o CSS cai automaticamente na camada de gradiente definida logo abaixo da
`url()` — nada quebra, mas a foto real não aparece.

| Arquivo               | Onde aparece            | Formato sugerido            |
| --------------------- | ----------------------- | --------------------------- |
| `hero.jpg`            | fundo do Hero           | paisagem, ≥ 2400px de largura |
| `about.jpg`           | retrato da seção Sobre  | 5:4, ≥ 1400px de largura      |

Basta salvar os arquivos com esses nomes nesta pasta.
